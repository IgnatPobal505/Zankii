# Zankii для iPhone

Исходный проект приложения: **[Zankii.xcodeproj](Zankii.xcodeproj)**. Версия 0.3.1, iPhone с iOS 16 и новее, горизонтальный экран в обе стороны. Все четырнадцать уровней, графика и музыка находятся внутри приложения. Для игры интернет не нужен.

## Как собрать на другом Mac

1. Скачай **весь репозиторий** [IgnatPobal505/Zankii](https://github.com/IgnatPobal505/Zankii) или выполни `git clone https://github.com/IgnatPobal505/Zankii.git`.
2. Открой `ios/Zankii.xcodeproj` в **Xcode 15 или новее** с установленной поддержкой iOS. Открывай именно этот проект, а не отдельный Swift-файл.
3. Для проверки в симуляторе выбери схему **Zankii**, затем модель iPhone и нажми **Run ▶**. При необходимости поверни симулятор горизонтально.
4. Проект подписывается командой **WaiWai, LLC** (Team ID `R4A779QVVY`), Bundle Identifier — `school.wai.zankii`. Если ты в этой команде App Store Connect, ничего менять не нужно. Без неё открой цель **Zankii → Signing & Capabilities**, выбери свой **Team** и смени Bundle Identifier на своё, но такие изменения не коммить.
5. Подключи iPhone, доверь устройству Mac и включи Developer Mode, если Xcode попросит. Выбери iPhone вместо симулятора и нажми **Run ▶**.

Node.js, npm, CocoaPods, сервер и сторонние пакеты для этой сборки **не нужны**. Файлы игры уже включены в репозиторий. Для установки на устройство Xcode создаёт подпись приложения через выбранный Team. [Инструкция Apple](https://developer.apple.com/documentation/xcode/running-your-app-on-simulated-or-physical-devices).

## TestFlight

Zankii заведена в App Store Connect команды WaiWai, LLC под названием **Zankii**. Первая сборка — версия 0.3.0 (1), загружена 29 октября 2026. Её получают внутренние группы тестировщиков **Grigoriy — iPhone and iPad** и **wai school**. Новые сборки попадают к ним автоматически.

Текущее обновление исходников — **0.3.1 (2)**. Оно содержит исправления управления, четырнадцать трасс и настоящий музыкальный файл. Эту новую версию здесь не собирали и не отправляли в TestFlight; следующий архив нужно подготовить на другом Mac.

Как выпустить новую сборку:

1. Увеличь **Build** (`CURRENT_PROJECT_VERSION`) на единицу. Номер сборки нельзя повторять. При заметном обновлении игры увеличь и **Version** (`MARKETING_VERSION`).
2. В Xcode выбери **Any iOS Device (arm64)**, затем **Product → Archive**.
3. В окне Organizer нажми **Distribute App → App Store Connect → Upload**.
4. Через 5–15 минут сборка появится в TestFlight.

В `Info.plist` указано `ITSAppUsesNonExemptEncryption = NO`: игра не использует шифрование, поэтому TestFlight не спрашивает об этом при каждой загрузке.

## Кнопки на iPhone

| Кнопка | Что делает |
| --- | --- |
| **HOLD** или касание игрового поля | Пока держишь — Wave летит вверх; отпустил — вниз. При перевёрнутой гравитации направление меняется, подсказка на HOLD тоже. |
| **Ⅱ Pause / Resume** | Остановить уровень и продолжить с того же места. |
| **↻ Restart** | Вернуться к стартовой панели текущего уровня. |
| **← Levels** | Открыть выбор четырнадцати уровней. |
| **♫** | Включить или выключить звук. Сначала звук выключен. |
| **⚙** | Открыть настройки эффектов. Открытие ставит игру на паузу. |
| **Start run / Try again / Next course** | Начать попытку, повторить после столкновения, перейти дальше после победы. |
| **Practice mode / Start sector** | Тренировка с выбором сектора и контрольными точками. Обычный рекорд не меняется. |

Во время игры экран не засыпает. Кнопки учитывают вырез экрана и нижнюю системную полоску. При сворачивании, блокировке или открытии системного окна игра отпускает управление и ставит паузу. Возвращение в приложение само по себе не продолжает уровень. Внешняя ссылка на GitHub открывается отдельно от игры.

## Музыка и ускорение

Встроен настоящий **At the Speed of Light — Dimrain47**, как в Bloodbath, с указанием автора и [CC BY-NC 3.0](https://creativecommons.org/licenses/by-nc/3.0/). Файл входит в некоммерческую версию и работает без интернета. В **Settings → Soundtrack** есть список других запрошенных композиций; их аудиофайлы пока не включены. **Add audio file** позволяет выбрать свою копию из «Файлов», **Remove file** — удалить импорт. Музыка сохраняется на устройстве; если хранилище недоступно — только до закрытия текущего сеанса. Файлы не отправляются на сервер.

На ускорениях короткие нажатия обрабатываются по их времени. При долгом зависании игра ставит паузу до движения персонажа. Если кадры долго отрисовываются медленно, **AUTO LOW FX** упрощает эффекты, сохраняя обычную механику и скорость.

## Устройство проекта

- `Zankii/AppDelegate.swift`, `SceneDelegate.swift` — запуск и состояние приложения.
- `Zankii/GameViewController.swift` — автономное окно WebKit, связь с игрой, пауза при уходе в фон, восстановление после остановки процесса WebKit.
- `Zankii/Web/` — подготовленная копия игрового движка, интерфейса и графики. Это локальные файлы, приложение не загружает сайт GitHub Pages.
- `Zankii/Assets.xcassets` — значок и фон запуска.
- `Zankii/PrivacyInfo.xcprivacy` — объявление отсутствия отслеживания и сбора данных приложением.

WebKit использует постоянное локальное хранилище для рекордов и настроек. Игровые файлы при запуске копируются в `Application Support/ZankiiWeb`, чтобы путь не зависел от имени папки установленного `.app`. Чтение WebKit ограничено этой папкой. Рекорды приложения и браузера отдельные; облачная синхронизация не добавлена.

## Когда меняется игра

Редактируй общие файлы игры **в корне репозитория**, затем на компьютере с Node.js 18+ выполни:

```sh
npm run ios:sync
npm test
```

Добавь обновлённую папку `ios/Zankii/Web` в тот же коммит. `npm run ios:check` проверяет, что она соответствует общим исходникам. Упаковка объединяет локальные модули в обычный `zankii.js`, чтобы игра работала из файлов приложения без HTTP-сервера. В Xcode нет скрытого шага сборки JavaScript.

Для повторного создания значка на Mac из корня репозитория: `swift scripts/create-ios-icon.swift`.

## Что проверено и что проверить после сборки

На компьютере разработки проверены автоматические тесты: четырнадцать трасс, порталы, столкновения, тренировка, одновременные нажатия, отмена касания, пауза/возврат приложения и актуальность автономных файлов. Проверены синтаксис Swift и структура файлов проекта. В браузере проверен интерфейс на размерах 667×375 и 844×390.

**Сборка текущей версии 0.3.1 и запуск на настоящем iPhone здесь не выполнялись** — они оставлены для другого Mac по договорённости. После сборки проверь:

- Первый запуск и повторное открытие без интернета, все четырнадцать уровней.
- HOLD и касание поля одновременно: отпускание одного пальца не отменяет второй.
- Пауза при блокировке, сворачивании и входящем звонке; после возврата требуется Resume.
- Настоящий MP3 без сети; пауза и возобновление музыки после звонка, возвращения и контрольной точки.
- Выбор файла из «Файлов», сохранение импортированной песни после перезапуска, Remove file.
- Участки 1.60×: короткие удержания, оба пальца, AUTO LOW FX; после долгой задержки кадра — безопасная пауза.
- Рекорды и настройки после закрытия/повторного запуска и обновления приложения.
- Экраны iPhone SE и iPhone с вырезом в обеих горизонтальных ориентациях; системная полоска не перекрывает кнопки.

Готовый `.ipa` и подпись учётной записи в репозиторий не включены.
